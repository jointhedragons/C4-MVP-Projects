# C4-MVP-Projects

## Three-Day MVP Development Repository

This repository supports teams of 4 members (1 lead + 3 developers) working on 3-day MVP projects. Each team follows a structured workflow designed to maximize learning and deliver functional prototypes.

## 🚀 Quick Start for Teams

### 1. Set Up Your Team Structure
```bash
./setup-team.sh
```
Follow the prompts to create your team's folder with all necessary templates.

### 2. Complete Your Team Meeting
- Fill out `DOCS/requirements-document.md`
- Break down tasks in your `Readme.md`
- Assign tasks to team members

### 3. Start Development
- Follow the 3-day workflow outlined in `PROJECT-WORKFLOW-GUIDE.md`
- Update documentation daily
- Focus on MVP functionality

## 🎯 Key Guidelines

### Branching Strategy
- **Main Branch:** Protected - no direct pushes
- **Team Branches:** Use naming convention: `LEAD_TEAM_Cycle_Project`

### Documentation Requirements
- **Readme.md:** Complete thought process (200-400 lines max)
- **Requirements Document:** Business and technical specifications
- **Iteration Summary:** Daily progress tracking

### Success Metrics
- Functional MVP delivered in 3 days
- Complete documentation
- All team members contribute meaningfully
- Valuable learning experience for everyone

## 💡 Tips for Success

- **Be Realistic:** 3 days is short - focus on core functionality
- **Communicate Often:** Daily check-ins and regular updates

- **Support Each Other:** Collaboration leads to better outcomes
