# AI Model Instructions and Rules

## General Guidelines
- Follow the established coding standards for this project
- Maintain consistency with the team's architectural decisions
- Ensure all generated code includes proper documentation
- Test all generated code before integration

## Project-Specific Rules
- Use the naming convention: `LEAD TEAM Cycle_number Project_code`
- All commits must reference the current iteration cycle
- Code must be compatible with the established tech stack
- Follow the three-day MVP constraints

## AI Model Constraints
- Generate code that can be completed within the 3-day timeline
- Prioritize functionality over perfection
- Focus on MVP features only
- Ensure generated solutions are realistic for team capabilities

## Documentation Requirements
- All generated code must include inline comments
- Update relevant documentation files when adding new features
- Maintain the project's README structure
- Keep documentation concise and actionable

## Code Quality Standards
- Write clean, readable code
- Follow language-specific best practices
- Include error handling where appropriate
- Ensure code is testable and maintainable

## Team Collaboration Guidelines
- Respect existing code patterns
- Communicate changes that affect other team members
- Update shared documentation when making architectural decisions
- Consider the impact on other team members' tasks

## Specific Instructions for This Project
- Focus only on MVP scope: authentication, HR job posting, talent profiles, and AI-based recommendations.
- Ensure GitHub repository is updated daily with proper commit messages referencing the cycle.
- Prioritize frontend usability and clean UI before extending backend logic.
- Use mock data in Redux Toolkit for the first cycle, then integrate the AI API once the UI flows are stable.
  
## Technology Stack Constraints
- Frontend Framework: React (with React Router for navigation).
- State Management: Redux Toolkit with Local Storage persistence.
- UI & Styling: CSS, Bootstrap (grid and flex utilities only), optional Tailwind if approved.
- Forms & Validation: React Hook Form where applicable.

## Performance Requirements
- UI must remain responsive and accessible across desktop and mobile.
- The system must handle at least 50 job posts and 50 talent profiles locally without lag.
- AI API responses should load within 2–3 seconds; fallback to dummy/mock data if slower.
- CRUD operations must execute in under 100ms for a smooth UX.
